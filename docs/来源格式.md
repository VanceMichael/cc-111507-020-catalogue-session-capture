# 合作馆联合目录来源格式

这是机构 HTTP 联合目录网关，不要求实现 Z39.50 BER。POST /catalogue/open 创建独立 session；POST /catalogue/search 接受 session、resultSetName、query、replaceIndicator，返回 resultCount/generation。POST /catalogue/present 接受 session、resultSetName、generation、start(1-based)、count、preferredSyntax，返回 numberOfRecordsReturned、nextResultSetPosition、records 和 diagnostics。每条 records 是 retrievalRecord 或 surrogateDiagnostic，整段失效走 operationDiagnostic。支持 MODS XML 与 UTF-8 MARCXML；来源书目身份取正文标识，不能拿 result position 当主键。closed/expired 后须重新搜索且不得复用旧序号。

`fixtures/scenarios.json` 给出本机来源入口和允许读取的资源；`GET /manifest` 返回同样的来源描述。`GET /trace` 返回当前进程内真实来源访问记录。资源接口为 `GET /files/百分号编码的资源名`，支持单段 Range、ETag 和 If-Match；资源名必须出现在来源清单中。数据不是新闻原文，不连接真实客户或设备。

格式参考：https://www.loc.gov/z3950/agency/。本项目只承诺上文列出的范围；未列出扩展应保留原文并明确不支持，不能假装完整解析。
